For PI 2026-Q3, we have identified four key epics: Container Security, CI/CD Pipeline Security, GitLab Migration, and Grafana Dashboard Configuration.
Epic 1 – Container Security: Focus on container image vulnerability scanning, container hardening, and remediation of identified security issues. Stories will cover image scanning, Docker/container security best practices, and resolution of security findings.
Epic 2 – CI/CD Pipeline Security: Focus on securing CI/CD pipelines through automated security scanning, secrets management, and pipeline hardening. Stories will cover security scan integration, credential protection, and remediation of pipeline security issues.
Epic 3 – GitLab Migration: Focus on migrating repositories and CI/CD pipelines to GitLab while maintaining functionality and access controls. Stories will cover repository migration, CI/CD migration, and GitLab access, integration, and migration issues.
Epic 4 – Grafana Dashboards Configuration and Issues: Focus on configuring dashboards, monitoring and alerts, and resolving dashboard-related issues. Stories will cover dashboard configuration, alert setup, and dashboard troubleshooting and improvements.
